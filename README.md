# Bubble · 端到端加密聊天

一个零依赖、自托管的端到端加密临时聊天工具。服务端只转发和存储密文，永远看不到聊天内容。

## 简述

- **前端**：`index.html` + `js/chat.js`，基于 UIGG 框架（`https://ui.gg` 远程 CDN）。
- **后端**：`api.php`，纯 PHP、无数据库、无 Composer、无第三方扩展。
- **加密**：浏览器用 WebCrypto（PBKDF2 派生密钥 + AES-GCM）在本地加解密。密码**永不上传**，服务端只收到房间号（作为存储桶 key）和加密后的密文。
- **存储**：每个房间是一个 JSON 文件 + 附件 blob 目录，位于 `rooms/`。
- **特性**：文字 / 图片 / 文件传输、在线人数显示、房间清空、退出、旧大房间自动瘦身。

## 部署

**环境要求**

- PHP ≥ 7.4（推荐 8.x），需 `rooms/` 目录**可写**（PHP 进程有写权限）。
- 任意 Web 服务器（Nginx/Apache）或 `php -S` 临时调试均可。
- `api.php` 顶部已 `ini_set('memory_limit','1024M')`；若主机禁用 `ini_set`（部分 宝塔/PHP-FPM 配置），需手动在 `php.ini` / `.user.ini` 设置 `memory_limit ≥ 512M`。

**步骤**

1. 将整个目录上传到网站根目录（如 `htdocs/`、`www/` 或子目录）。
2. 确保 `rooms/` 可被 PHP 写入（不存在会自动创建；建议 `chmod 755`）。
3. 访问 `index.html`（或把 `index.html` 设为默认文档）。
4. 建议启用 **HTTPS**，否则传输内容可被中间人截获。

> 调试：`php -S 127.0.0.1:8099 -t .` 然后浏览器开 `http://127.0.0.1:8099/index.html`。

## 用法

1. 打开页面，进入登录框。
2. 填写三项后点 **Enter**：
   - **Number**：房间号（自定义，相同号码的人进同一房间）。
   - **Password**：房间密码，**同时作为加解密密钥**。所有进同一房间的人必须填写相同密码，否则无法解密彼此消息。
   - **Name**：显示名，**每次手动填写**（不记忆、不缓存，避免隐私残留）。
3. 进入后：
   - 输入框回车发送；`Ctrl+Enter` 换行。
   - 点 📁 图标发送图片 / 文件（单文件上限 **50 MB**）。
   - 标题处 🗑 图标 = **清空聊天记录**（二次确认）。
   - 标题处 ✕ 图标 = **退出房间**（二次确认）。
4. 房间号后实时显示在线人数，例如 `#1 · 3 online`。

**房间生命周期**

- 仅当房间内**所有用户都离线且持续约 3 分钟**，房间才会被自动删除（含消息与附件）。
- 「清空聊天记录」只清消息，**不会踢出在线成员**。

## 注意事项

- **密码即密钥**：密码丢失无法找回，历史消息也永远无法解密。请与同房成员通过其他可信渠道约定密码。
- **服务端零知识**：服务器只存密文与房间号，运营方无法读取内容、也无法帮你恢复密码。
- **UIGG 远程依赖**：前端通过 `https://ui.gg/lib/uigg.js` 与 `uigg.css` 加载框架。该 CDN 不可达时整页会白屏失效——如对可用性要求高，建议把 uigg 资源改为本地自托管。
- **传输安全靠 HTTPS**：端到端加密保护内容，但不保护「谁在和谁通信」的元数据；公网部署务必上 HTTPS。
- **内存配置**：超大历史房间首次访问会触发自动压缩。若 `memory_limit` 过低（<512M）且主机禁 `ini_set`，超大房间首访可能 500。
- **旧房间自愈**：早期版本曾把文件以 base64 内联进房间 JSON（可达数十 MB），新版本首次访问会自动剔除这些不可读残留并将其瘦身至约 4 MB，无需手动清理。
- **消息上限**：每个房间保留最近 **500** 条消息（环缓冲，最旧自动丢弃）。
- **责任边界**：端到端加密 ≠ 服务端无法封禁/删除房间。服务端仍可按运营规则处置存储文件。
- **合规使用**：请仅在合法、双方知情同意的场景下使用。

目录结构

```
.
├── api.php            # 后端：无状态中继 + 房间文件存储
├── index.html         # 前端入口（引用远程 UIGG + 本地 chat.js）
├── js/
│   └── chat.js        # 前端逻辑：加密、轮询、文件、UI
├── styles/
│   └── chat.css       # 聊天界面样式（uigg 框架样式走 CDN）
├── images/            # 图标等资源
└── rooms/             # 运行时生成：房间 JSON + 附件 blob（需可写）
```
